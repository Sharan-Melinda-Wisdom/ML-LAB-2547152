## Machine Learning Lab

This repository contains the programs and exercises completed as part of the Machine Learning Lab.The lab focuses on understanding the basic concepts of Machine Learning and implementing different supervised and unsupervised learning algorithms using Python.

## Objectives

- Understand the basic concepts of Machine Learning.
- Learn how to preprocess and analyze datasets.
- Implement basic Machine Learning algorithms.
- Train and test ML models using Python.
- Evaluate model performance using suitable metrics.
- Understand the practical applications of different algorithms.

## Topics Covered

The repository includes implementations and exercises related to:

- Data Preprocessing
- Exploratory Data Analysis
- Train-Test Split
- K-Nearest Neighbors (KNN)
- Classification
- Regression
- Decision Trees
- Other basic Machine Learning algorithms
- Model Evaluation
- Accuracy, Precision, Recall and F1-Score
- Confusion Matrix
- Data Visualization
